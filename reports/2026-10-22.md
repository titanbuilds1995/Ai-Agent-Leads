# BLOCKERS — things only Rodrigo can resolve

The build environment had **no credentials** (no `APIFY_TOKEN`, `ANTHROPIC_API_KEY`, Gmail OAuth JSON, or Twilio keys), so every step below was built and tested against fixtures, not live data. Nothing here blocks the code; each item blocks turning that step live.

1. **`.env` credentials.** Copy `.env.example` to `.env` and fill in: `APIFY_TOKEN`, `ANTHROPIC_API_KEY`, `GMAIL_OAUTH_JSON` (path to the OAuth client JSON for the *dedicated* outreach mailbox), `GMAIL_SENDER`, `REPORT_TO`, `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_MESSAGING_SERVICE_SID`, `WEBHOOK_PUBLIC_URL`.
2. **First live scrape needs a 10-minute look.** Run `make run-daily` once and open the newest file in `raw/`. If `ingest.sources.realtor.count` or `zillow.count` in the printed summary is 0 while the raw file has items, a field name differs from what the mapper expects (`titan/ingest/realtor.py`, `zillow.py`); the raw dump shows the real name. Actor ids and search URL templates are in `config.yaml → ingest.apify` if you prefer different actors.
3. **Gmail OAuth consent** is interactive: run `make gmail-auth` once on a machine with a browser (it prints a URL), which writes `secrets/gmail_token.json`. Cron then refreshes the token on its own.
4. **Twilio A2P 10DLC registration** must be approved on the Messaging Service before texts deliver; the webhook URL (`<WEBHOOK_PUBLIC_URL>/twilio/inbound`) must be set as the service's inbound request URL and `make webhook` must be running (ngrok or the VPS public IP).
5. **Operator inputs that were blank** were filled with defaults (see DECISIONS.md #1–#2): price range, formula numbers, EMD, sender phone `+13055550100` (placeholder — **replace `operator.sender_phone` and `operator.mailing_address` in `config.yaml` before sending anything**), and three example emails written in the style of the prep doc. Paste your real emails into `config.yaml → outreach.example_emails` to tune the voice.
6. **Florida DBPR licensee lookup** (enrichment rung d) hits `myfloridalicense.com` with a plain GET; the site sometimes requires a session cookie. If `make run-daily` logs many `rung_dbpr` warnings, set `enrichment.dbpr_enabled: false`; the other four rungs still run.
